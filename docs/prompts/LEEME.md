# Paquete del proyecto de nacionalidad

## Qué hay

- `nacionalidad/` — la carpeta del proyecto. Ábrela con Claude Code tal cual.
  - `AGENTS.md` — las reglas del asesor honesto y el alcance fijo. Codex y otros agentes lo leen.
  - `CLAUDE.md` — hace que Claude Code cargue `AGENTS.md` automáticamente.
  - `docs/prototipo-nacionalidad.html` — el diseño aprobado.
  - `docs/IDEAS.md` — donde apuntas cada idea nueva para que no desvíe el trabajo.
- `1-PROMPT-ESTA-NOCHE-investigacion.md` — lo que pegas esta noche en Claude Code.
- `2-PROMPT-DESPUES-construccion.md` — para cuando las bases estén cerradas. No lo uses todavía.

## Pasos para esta noche

1. Descomprime y copia la carpeta `nacionalidad/` donde quieras trabajar. Mejor una carpeta nueva y aparte, no la del proyecto antiguo.
2. Abre Claude Code sobre esa carpeta.
3. Activa el modo que acepta cambios automáticamente y permite la búsqueda web, para que no se pare a pedirte permiso.
4. Pega el contenido del prompt 1.

## Mañana

1. Lee `docs/investigacion/RESUMEN.md` y `docs/ALERTAS.md`.
2. Cerramos juntos `docs/BASES.md` y preparamos la skill del proyecto.
3. Solo después, el prompt 2.
